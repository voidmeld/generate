# Evidence and limits

Use these behavioral suites to refute the owning contract.
After you change a public boundary, run the actual consumer workflows.
Record the exact commits, commands and exit codes in the change report.

| Contract | Executable evidence | Limit |
| --- | --- | --- |
| Roblox destination, publication facts, verification requests, closure and reconcile checks, size units | [Roblox publication](../tests/roblox-publication.verify.luau) | Fixture records prove validation and refusal. They cannot prove that a destination accepted the content or that a host ran it. |
| Deterministic plan, authority, lineage, strict independent review and unchanged-receipt continuation | [Core](../tests/core.verify.luau) | Injected effects cannot establish truthful rights, review independence or provider output. |
| Structured content, reviewer streams and Open Cloud operations | [Adapters](../tests/adapters.lute.verify.luau) | Fixture hosts do not prove native rigging, playback, live transport or artistic quality. |
| One-attempt record, stop-on-refusal, ambiguous-outcome recovery, moderation readback, native save and resume | [Delivery](../tests/delivery.lute.verify.luau) | Scripted transports prove the contract. They cannot prove live moderation, ownership or that an asset loads. |
| WAVE measurement, ffmpeg command construction and parsed tool output | [Media](../tests/media.lute.verify.luau) | A measurement is not an audition. |
| Asset and dependency census, ownership, permission partitions, reference provenance rows and binary readback | [Asset lane](../tests/asset-lane.lute.verify.luau) | Scripted replies prove validation. Metadata cannot prove remote content equality or effective native load. |
| Native Studio plan grants, one-attempt transcripts, ambiguous-call retry refusal and exact capture bytes | [Native transcript](../tests/native-transcript.lute.verify.luau) | Fixture hosts prove binding and refusal. They cannot prove that a live Studio ran the call or that a capture shows the retained asset. |
| Recipe binding, one provider attempt, immutable references, script and output drift, blind packets and measurements | [Image lane](../tests/image-lane.lute.verify.luau) | Mock process effects and consumer thresholds cannot establish provider availability or acceptance. |
| Pixel transforms and measured image refusals | [Transforms](../tests/image-transforms.lute.verify.luau) | Small fixture codecs prove declared calculations. They do not prove all formats or perception. |
| Authored-brief diagnostics and exact dependency resolution | [Consumer](../tests/consumer.verify.luau), [lint](../tests/lint.lute.verify.luau), [dependency](../tests/dependency-source.lute.verify.luau) | Static diagnostics complement runtime validation. A pinned dependency is not live service evidence. |

[The API](api.md) owns the acceptance and recovery rules. [Native retention](native-codegen.md) defines preservation and readback.
[Benchmarks](benchmarks.md) measure framework overhead only.
None of these replaces an inspection of the delivered content in its real consumer.
